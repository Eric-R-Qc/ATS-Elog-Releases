# ATS Elog v1.0.5 Beta 10

## Français

- L’alerte de mise à jour du plugin a été simplifiée : le bouton `OK` ferme la fenêtre.
- Après confirmation, une petite bannière cliquable rappelle qu’une mise à jour du plugin est disponible.
- La bannière ouvre les instructions de téléchargement et disparaît automatiquement après la détection du nouveau DLL.
- Les mises à jour Android restent séparées et gardent leur bouton de téléchargement direct.
- Archive ZIP reconstruite avec une arborescence plus claire pour les outils d’extraction.

Fichiers :

- `ATS_Elog_1.0.5_Beta10.zip` — plugin, interface Web et APK de test inclus.
- `ATS_Elog_Mobile_1.0.5_beta10.apk` — application Android expérimentale.
- `SHA256SUMS-1.0.5-Beta10.txt` — empreintes officielles.

## English

- The plugin update alert is simplified: the `OK` button closes the dialog.
- After confirmation, a small clickable banner reminds the user that a plugin update is available.
- The banner opens download instructions and disappears automatically when the new DLL is detected.
- Android updates remain separate and keep their direct download button.
- The ZIP archive was rebuilt with a clearer extraction layout.

Download only from this official repository and compare SHA-256 checksums when needed.
