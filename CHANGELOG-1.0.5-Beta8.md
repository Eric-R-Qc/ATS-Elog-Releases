# ATS Elog v1.0.5 Beta 8

## Français

- Nouveau dépôt officiel de téléchargements : `ATS-Elog-Releases`. Le code source ATS Elog reste privé.
- Les contrôles de mise à jour du plugin recherchent uniquement un ZIP listé dans le manifeste officiel de ce dépôt.
- L’APK Android recherche uniquement un APK listé dans ce manifeste et peut le proposer au téléchargement.
- Renforcement gratuit de la DLL : ASLR, DEP, Control Flow Guard, protection de pile et contrôles SDL.

Fichiers :

- `ATS_Elog_1.0.5_Beta8.zip` — plugin, interface Web et APK de test inclus.
- `ATS_Elog_Mobile_1.0.5_beta8.apk` — application Android expérimentale.
- `SHA256SUMS-1.0.5-Beta8.txt` — empreintes officielles.

## English

- New official download-only repository: `ATS-Elog-Releases`. ATS Elog source code remains private.
- Plugin update checks accept ZIP files only from this official repository manifest.
- The Android APK checks only APK files from this official repository manifest and can offer the download.
- Free DLL hardening: ASLR, DEP, Control Flow Guard, stack protection and SDL checks.

Download only from this release and compare SHA-256 checksums when needed.
