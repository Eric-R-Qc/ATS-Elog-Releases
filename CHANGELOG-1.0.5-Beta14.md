# ATS Elog v1.0.5 Beta 14 — version finale 1.0.5

Cette version finale regroupe les améliorations des bêtas 7 à 14 de la série 1.0.5.

## Français

### Installation et plateformes

- Ajout d’un installateur PC guidé en français, anglais, allemand et espagnol.
- Première version de l’application Android et instructions pour l’application web sur PC, Android et iOS.
- Vérification d’intégrité SHA-256 des téléchargements et séparation du dépôt public de distribution du code source privé.

### Affichage et LogBooks

- Améliorations de l’affichage mobile, des traductions et du fonctionnement hors ligne.
- Corrections dans les LogBooks : doublons d’activités, statut de connexion et version affichée.
- Bandeau de mise à jour déplacé sous l’en-tête bleu pour ne plus masquer le minuteur HOS.
- Bouton de téléchargement et nom du ZIP centrés dans la fenêtre de mise à jour.

## English

### Installation and platforms

- Added a guided PC installer in French, English, German and Spanish.
- First Android app version and web app instructions for PC, Android and iOS.
- Added SHA-256 integrity checks and a clear separation between the public download repository and the private source code.

### Display and LogBooks

- Improved mobile layout, translations and offline behavior.
- LogBooks fixes for duplicate activities, connection status and displayed version.
- Moved the update banner below the blue header so it no longer hides the HOS timer.
- Centered the download button and ZIP filename in the update dialog.
