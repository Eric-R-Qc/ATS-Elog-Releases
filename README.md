# ATS Elog — Official Downloads

This repository contains only official compiled ATS Elog downloads, release
notes and SHA-256 checksums.

The ATS Elog source code is private and is not published here.

## Download

### Update test

1. Install the **Beta 8 ZIP** on the PC running ATS:
   [Download ATS Elog 1.0.5 Beta 8](https://github.com/Eric-R-Qc/ATS-Elog-Releases/raw/main/downloads/ATS_Elog_1.0.5_Beta8.zip)
2. For Android, install the **Beta 8 APK**:
   [Download ATS Elog Mobile 1.0.5 Beta 8](https://github.com/Eric-R-Qc/ATS-Elog-Releases/raw/main/downloads/ATS_Elog_Mobile_1.0.5_beta8.apk)
3. Beta 8 will then detect the currently available Beta 9 update.

Checksums are provided in `SHA256SUMS-1.0.5-Beta8.txt`.

Download only from this repository or from the official SCS Software Forum
topic. Mirrors, file hosts and re-uploaded packages are unsupported and may be
outdated or modified.
