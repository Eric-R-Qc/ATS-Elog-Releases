# ATS Elog — Téléchargements officiels

Ce dépôt contient uniquement les téléchargements compilés officiels d’ATS Elog,
les notes de version et les contrôles SHA-256.

Le code source d’ATS Elog est privé et n’est pas publié ici.

## Télécharger la version actuelle

**ATS Elog v1.0.5 Beta 14**

[Télécharger le ZIP officiel pour PC](https://github.com/Eric-R-Qc/ATS-Elog-Releases/raw/main/downloads/ATS_Elog_1.0.5_Beta14.zip)

Après l’extraction, lancez `INSTALLER_ATS_Elog.bat`, choisissez votre langue,
puis indiquez le dossier `bin/win_x64` de votre installation d’American Truck
Simulator. Les instructions complètes sont incluses dans le ZIP.

Contrôle d’intégrité : [SHA256SUMS-1.0.5-Beta14.txt](SHA256SUMS-1.0.5-Beta14.txt)

## Améliorations récentes

Depuis la reprise du développement, ATS Elog a notamment reçu :

- un installateur PC guidé, disponible en français, anglais, allemand et espagnol ;
- une application Android expérimentale et les instructions pour l’application web sur PC, Android et iOS ;
- la détection des mises à jour du plugin et de l’application Android depuis la source GitHub officielle ;
- des notifications Android pour les nouvelles mises à jour ;
- une vérification SHA-256 et une séparation claire entre le dépôt public de téléchargements et le code source privé ;
- des améliorations d’affichage mobile, de traduction et de mode hors ligne ;
- des corrections LogBooks : doublons d’activités, statut de connexion hors ligne et version affichée ;
- un bandeau de mise à jour discret placé sous l’en-tête, sans masquer le minuteur HOS.
