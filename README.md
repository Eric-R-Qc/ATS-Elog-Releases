# ATS Elog — Téléchargements officiels

Ce dépôt contient uniquement les téléchargements compilés officiels d’ATS Elog, les notes de version et les contrôles SHA-256. Le code source d’ATS Elog est privé et n’est pas publié ici.

## Télécharger la version actuelle

**ATS Elog v1.0.6**

- [Télécharger le ZIP officiel pour PC](downloads/ATS_Elog_1.0.6.zip)
- [Télécharger l’APK Android](downloads/ATS_Elog_Mobile_1.0.6.apk)
- [Lire le changelog 1.0.6](CHANGELOG-1.0.6.md)
- [Vérifier les empreintes SHA-256](SHA256SUMS-1.0.6.txt)

Après l’extraction, copiez le contenu du dossier `win_x64` fourni dans le dossier `bin/win_x64` de votre installation d’American Truck Simulator. Le ZIP comprend `HqSaveDecoder.exe`, requis par ATS Elog pour lire les données de sauvegarde ATS. Les instructions détaillées, en quatre langues, sont incluses dans le ZIP.

## Principales nouveautés 1.0.6

- Profils de conducteur synchronisés sur PC, Web App et APK Android.
- Conduite personnelle bobtail et LogBooks améliorés.
- Mode Simulation USA : temps de conduite, de service, pause et cycle 70 h / 8 jours.
- Alertes HOS, vibration Android optionnelle et écran maintenu allumé en premier plan.
- Timeline LogBooks colorée, activités par conducteur et conservation chronologique des 14 derniers jours.
- Documentation intégrée, traductions, fuseaux horaires et synchronisation des réglages améliorés.
